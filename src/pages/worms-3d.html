02 / The 3DS port

Not emulated. Rebuilt.

The game’s own code, compiled for the New Nintendo 3DS processor.

From recovered source

Worms 3D’s GameCube code is being recovered function by function. The port compiles that code for the 3DS ARM processor, keeping the original game rules, AI and scripts.

Drawn by the 3DS GPU

The GameCube graphics calls are translated to the 3DS PICA200 through citro3d. Lighting runs in the vertex shader, and level geometry, textures and render state are cached on the GPU.

Made for the upper screen

The full game runs on the 400 × 240 upper screen, with the camera widened for its 5:3 shape. Menus, videos, languages, matches and saves all work.

Bring your own game

No game files are included. A small macOS extractor turns your own Worms 3D disc image into a single assets.worms package that the port reads from the SD card.

Measured on New Nintendo 3DS20–25fps

Matches already run between 20 and 25 frames per second on real New 3DS hardware, without trouble. Optimization continues.

03 / Mods & Ultimate Mayhem

More worms. More mayhem.

This port is built to be modded.

Drop a .worms package into the mods folder on the SD card and the port mounts it on top of the game: it can replace any original file or add new ones, without touching your copy of the game.

The plan goes far beyond the original: clothing and accessories for the worms, and other content from Worms 3D’s sequel, Worms Ultimate Mayhem, ported into this game.

  • Ultimate Mayhem headwearA military cap taken from Ultimate Mayhem, rebuilt in the GameCube format and worn in-game on 3DS.
  • Dominicano voice bankA brand-new speech bank with 66 lines, selectable like the original voices.
  • Worm wardrobeHats, glasses, outfits and more customization for every team.
  • More from Ultimate MayhemFurther additions from the sequel, brought over to this port.

05 / Questions & answers

Before the next turn.

Can I download it yet?

Not yet. The port is unreleased and around halfway through development. Follow the Forge for the first release.

Does it work on an original Nintendo 3DS?

The port targets New Nintendo 3DS and New Nintendo 2DS XL, which have the extra CPU speed and memory it needs.

Will the lower screen be used?

Yes. Today the game runs entirely on the upper screen and the lower screen has no interface yet. A touch interface is planned.

Do I need my own copy of the game?

Yes. No game files are included. The extractor builds the port’s data package from your own Worms 3D disc image.
