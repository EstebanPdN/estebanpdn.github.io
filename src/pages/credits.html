Credits · sources · permissions

Who made these assets?

This portfolio brings together original project work, owner-supplied references, game artwork, product photographs, manuals, captures, software, and fonts. The register below records the available source evidence for every file shipped in assets/.

A credit is not a reuse licence

Nintendo, Sega, Atari, id Software, and other rights holders retain rights to their games, characters, logos, manuals, and promotional artwork. An archive, shop page, search result, or attribution does not establish permission to reproduce those materials. Some permissions for the original portfolio assets could not be verified; their sources and uncertainty are recorded rather than described as cleared.

The files remain because Esteban chose to preserve the current portfolio resources and publish their attribution evidence with the project. That decision is not a claim that every right or licence has been independently confirmed.

Per-file provenance register

Each entry includes its exact relative path, SHA-256 digest, the closest matching source note, and a careful permission status. Source links point to the material recorded by the project; a named licence still needs confirmation against the rights holder and the intended use.

How the register describes permission

  • Licence named in a source recordThe record names terms; the rights holder and coverage still need checking.
  • Source recorded, permission not establishedA source is identified, with no reuse grant recorded.
  • Permission explicitly unknownThe source notes itself say that the permission or licence is unknown.
  • Context only or no source noteThe manifests do not establish a file-specific source or permission.

Creators and source families

The project records source links for archived Nintendo artwork and manuals, console and cartridge photographs, development captures, community game icons, and original interface references. Its font records name Pixelify Sans, DM Sans, Nunito, Cormorant Garamond, Fondamento, Barlow Semi Condensed, and Nintendo DS by cheezonpeaz41. Where bundled font licence text is present, it remains alongside the relevant files.

The Sony PVM-4300 photograph is attributed to Shank Mods under CC BY-SA 4.0 in the project record. The blue Nintendo DS and Game Boy Advance photos are recorded as public-domain photographs by Evan-Amos. Other hardware images include a shop-catalogue cartridge photo whose reuse terms are not stated in the source record. The Star Fox Arwing model credits lllll440 and records CC BY 4.0; the per-file register links that source and the noted terms.

Artwork archives, manuals, supplied project files, and image hosts are not necessarily the original rights holders. Please use the register to follow each chain of evidence and check the original licence text before reusing an asset.

All third-party marks and works remain with their respective owners. No blanket licence is granted for this repository’s source code or bundled media.
