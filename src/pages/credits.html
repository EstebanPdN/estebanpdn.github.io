Nintendo DS menu reference

The Super Mario 64 DS page uses native menu sprites extracted from an owner-supplied Nintendo DS reference. The Nintendo UI pixels are preserved, with quieter LCD lines; the original system screens keep their light palette in both themes. Clock numerals and the battery retain their native reference pixels. The note document and wireless indicator are custom pixel icons. The Discord button uses the original Discord symbol in its original proportions, in black or white for the selected theme. The game logo is based on the high-resolution original Nintendo artwork. UI asset sources and processing.

Star Fox typography: Pixelify Sans, distributed under the SIL Open Font License. Its original font and license accompany the site.
