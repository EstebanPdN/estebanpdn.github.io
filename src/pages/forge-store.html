What it does

A real store, made for two screens

I made forge.store for my ports and for the community homebrew I use every day. Everything happens on the console: no PC, no copying files around, no guessing which folder each game wants.

  • All my ports

    Every Esteban’s Forge port with its banner, screenshots, trailer, requirements and release history.

  • Community homebrew

    Curated emulators and tools, plus optional Universal-DB integration and search.

  • Look before you install

    A native GitHub reader for READMEs, releases, images and repository details.

  • Download, install, play

    Download queue, verified installs that survive a power cut, uninstall, SD browser and direct launch.

  • Made for two screens

    400×240 above, 320×240 touch below, crisp native type, light and dark themes and eight languages.

  • Keep it current

    Built-in store updates on every launch, and update marks for apps you installed with FBI or Universal-Updater too.

Get started

Install it in a couple of minutes

You need an Old or New Nintendo 3DS, 3DS XL, 2DS or 2DS XL with custom firmware (Luma3DS), and FBI or the Homebrew Launcher.

  1. Install the CIA

    Open FBI, choose Remote Install → Scan QR Code and scan this code. You can also copy the CIA to your SD card and install it from FBI.

  2. Or use the 3DSX

    Copy forge-store.3dsx to sdmc:/3ds/forge-store/ and open it from the Homebrew Launcher.

  3. Enter the store

    Launch forge.store from the HOME Menu, choose a theme and you’re in.

  4. Let the trailers arrive

    With Wi-Fi on, the Store resources package (16 MB of trailers) downloads in the background. You can browse and install while it finishes.

Scan with FBIAlways points to the newest build.

  • Keep at least 100 MB free on the SD card.
  • Each game needs its own extra space.
  • Check your download against SHA256SUMS.

Good to know

Questions

Does it include games or ROMs?

No. No ROMs, game data, DSP firmware or saves are included. Ports that need your own game files tell you exactly which file to place on the SD card, and the store shows the file it found once it is accepted.

What about the sound firmware?

Games need dspfirm.cdc for sound. If it is missing, the store dumps it from your own console automatically, like DSP1 does.

How do updates work?

Every launch checks for a newer store build. Choose Yes to download, verify and install it, or No to close the store. If GitHub can’t be reached, the store just continues normally.

What happens if the power goes out mid-install?

Installs are transactional. Every installation writes a recovery inventory before it touches an existing file. On the next launch, unfinished work is undone and the previous version stays; an installation that was already complete is finished.

I already installed apps with FBI or Universal-Updater

The store recognizes them by their CIA title, their .3dsx and other files, and Universal-Updater’s own record. They show Installed, or Update when a newer release is available.

Does it work offline?

Yes. The bundled catalog and screenshots work without a connection. Wi-Fi is only needed for downloads, updates and GitHub pages.

Where does it keep its files?

Settings, installed metadata, caches and temporary files live under sdmc:/3ds/forge-store/. Updating the store never requires deleting that folder. Settings → Clean video cache frees the trailer space.

Community and bug reports

Found a bug? Have an idea?

Join the Discord for updates, support and suggestions. Report reproducible problems on GitHub with your console model, CIA or 3DSX, and the steps to reproduce it. Never attach ROMs, memory dumps or personal SD contents to a public report.
