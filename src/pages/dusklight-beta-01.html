Prepare the game files

Use the Forge 3DS Converter with your own GameCube Twilight Princess ISO. The converter supports USA or PAL revision 0 (GZ2E01 or GZ2P01).

  • Windows (64-bit)
  • macOS (Apple silicon)
  • macOS (Intel)
  • Linux (64-bit)
How to use the converter
  1. Extract the complete download and open Forge 3DS Converter.
  2. Select Dusklight and drop your ISO onto the app, or choose it with the file picker.
  3. When conversion finishes, find zelda.twilight beside your ISO.
  4. On the 3DS SD card, create /3ds/DuskLight/ if needed. Copy the file to /3ds/DuskLight/zelda.twilight, then launch Dusklight.

Send a dump

Tap DUMP on the lower screen and wait for DONE. ZIP one completed folder from /3ds/DuskLight/dumps/. Include dump.dpk and send each dump separately.

One ZIP, up to 50 MB.
