Prepare the game files

Use the Dusklight extractor with your own GameCube Twilight Princess ISO (USA or PAL revision 0, GZ2E01 or GZ2P01). It runs on Windows, macOS and Linux with Python 3.

Download ROM extractor
How to use the extractor

  1. Gather your files

    Unzip the extractor. In the same folder, place your GameCube ISO and name it twilight.iso.

  2. Build the pack

    Open a terminal in that folder. Run the command for your computer and wait for it to finish.

  3. Copy to your SD card

    Copy the new pack into /3ds/DuskLight/. Create the folder if needed. Reinsert the card and launch Dusklight.

Send a dump

Tap DUMP on the lower screen and wait for DONE. ZIP one completed folder from /3ds/DuskLight/dumps/. Include dump.dpk and send each dump separately.

One ZIP, up to 50 MB.
