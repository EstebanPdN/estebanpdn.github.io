Prepare the game files

Use the Dusklight extractor with your own GameCube Twilight Princess ISO (USA or PAL revision 0, GZ2E01 or GZ2P01). It runs on Windows, macOS and Linux with Python 3.

Download ROM extractor
How to use the extractor
  1. Extract the ZIP and put your ISO in the same folder as twilight_pack.py. The command below assumes that the ISO is named twilight.iso.
  2. Open a terminal in that folder and run: 
    python3 twilight_pack.py --input "twilight.iso" --output "zelda.twilight"
    On Windows, use py -3 in place of python3.
  3. When the extractor finishes, copy zelda.twilight to /3ds/DuskLight/zelda.twilight on the 3DS SD card. Create the DuskLight folder inside 3ds if needed, then launch Dusklight.

Send a dump

Tap DUMP on the lower screen and wait for DONE. ZIP one completed folder from /3ds/DuskLight/dumps/. Include dump.dpk and send each dump separately.

One ZIP, up to 50 MB.
