BEFORE YOU PRESS START

A few project answers.

01Can I download the 3DS port?+

There is no release yet. Super Mario 64 DS is in development at 75%, as shared by Esteban. Check the Forge progress page for its current status.

02Is this the Nintendo 64 version?+

This project is based on Super Mario 64 DS, the Nintendo DS edition. It is a separate project from Mario Kart 64 and from ports of the original Nintendo 64 Super Mario 64.

03Will it work on Old and New 3DS?+

Supported console models have not been announced for this project. Hardware compatibility will be documented when development produces results to share.

04When can I see gameplay or installation instructions?+

Development captures will appear here when there is more to show. There is no announced release date, installation method or performance target. Join the community to follow the project.
