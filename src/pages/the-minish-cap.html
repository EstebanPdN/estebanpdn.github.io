Before you begin

SIX QUESTIONS FROM THE COMMUNITY

A little advice from a friend.

The questions that keep coming up in the Minish Cap community, with answers checked against the project’s current documentation.

01

How do I install the port and keep it updated?

On a homebrew-enabled 3DS, install the CIA with FBI or launch the 3DSX through the Homebrew Launcher. Both formats and an FBI QR code are on the release page.

Put your own compatible .gba ROM in sdmc:/3ds/The Minish Cap 3DS/. Any filename works; the extension must be .gba. Installing the app does not supply the game ROM.

For later updates, open Settings → Update, select Stable or Pre-release, and read the changelog. Save first: a successful update closes the app. You can also install a new CIA over the old one without deleting your save folder.

02

Which screen settings should I use?

Esteban recommends Stretch + Bilinear for everyday play on both Old and New 3DS. Choose Original + Bilinear if you prefer the original proportions with borders.

Wide shows more of the world, but some rooms can have visual issues. Try the display guide in the game and gallery chapter to compare the framing and pixel styles.

03

USA or Europe? Can I use a patched ROM?

Both clean USA and European ROMs are supported, with automatic region detection. The European version is recommended because it received the most testing and includes several languages, including English.

European gameplay backports are already integrated into the port, so they do not require a separate ROM patch. Other ROM hacks and translation patches are not automatically compatible with a native port. Start with a clean supported ROM and consult the README’s checksums if detection fails.

04

Do I need a New 3DS? Is this an emulator?

A New 3DS is not required. Both Old and New Nintendo 3DS are supported, with different performance profiles. New hardware has additional performance features and C-Stick turbo.

This is a native Nintendo 3DS port, based on the game’s decompilation and Project Picori, with a separate lower-screen interface. It is not a general GBA emulator or a Virtual Console injection. Questions about running it inside a 3DS emulator are a separate compatibility matter; the hardware support described here refers to Nintendo’s consoles.

05

Why doesn’t the randomizer option work?

The randomizer is a planned feature and is not available yet. The reserved option in Settings does not currently activate a randomizer.

A patched ROM or seed will not enable it. Check future release notes for news about this feature.

Current 3DS implementation notes
06

Can I bring my existing GBA save?

Compatible mGBA / VBA-M .sav files can be transferred manually. Back up your files first, close the game, and use a save from the same ROM region.

Place the save in sdmc:/3ds/The Minish Cap 3DS/: use tmc.sav for USA or tmc_eu.sav for Europe. Emulator save states are a different format. Renaming a save does not convert it between regions.

When updating an existing installation, keep the save and its companion files. If a legacy save is rejected, check the latest release notes before changing or deleting anything.

Still need a hand?

Our community is here to help. Join Esteban’s Forge on Discord for new releases, setup advice and a place to share your adventure.

For a crash or visual bug, press L + R + A to create a diagnostic dump in the game’s dumps/ folder. Attach the dump to a GitHub issue or share it in our Discord community. Include your console model, game version, ROM region and the steps that caused the problem.

No sound? In Luma3DS’s Rosalina menu, use Miscellaneous options → Dump DSP firmware, then restart the game.
