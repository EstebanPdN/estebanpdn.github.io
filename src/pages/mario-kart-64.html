3. Before starting the game

A quick pit stop.

Your console. Your game. Everything ready for the first race.

  1. 1

    Choose your build.

    Install the CIA with FBI, or use the full 3DSX with the Homebrew Launcher. The CIA is recommended for expanded application memory.

    Get the latest release
  2. 2

    Bring your own game.

    Place your compatible USA ROM in sd:/3ds/MK64/ and name it mk64.z64. It must use Z64 byte order.

  3. 3

    Let the first lap load.

    Launch the port to validate the ROM and create mk64.o2r. Keep the console charged during extraction. Future launches reuse this archive.

5. Driver’s handbook

Before you
hit the gas.

A few things worth knowing before the next race.

THE ORIGINAL MANUAL
01

Does it work on Old and New Nintendo 3DS?

+

The port has hardware profiles for both Old and New Nintendo 3DS. The installed CIA requests expanded application memory on both; Old models can take longer to launch and exit while the system changes memory mode. Performance varies by console, course and settings. The CIA is recommended for the expanded-memory path.

02

Which ROM do I need?

+

Provide your own legally obtained USA Mario Kart 64 ROM, in .z64 byte order. Name it mk64.z64 and place it in sd:/3ds/MK64/. Renaming a .n64 or .v64 file does not change its byte order; the README links a conversion tool. Game data is not included in the download.

03

Why is the first launch taking so long?

+

The console validates your ROM and builds mk64.o2r. This first extraction can take a long time; keep the battery charged. You can close the lid while it continues, or press START to cancel safely. Later launches reuse the completed archive. For faster setup, create the archive with SpaghettiKart on a computer and copy it alongside your ROM.

04

Is this a 60 FPS port?

+

The original simulation runs at 30 Hz. Adaptive interpolation can add an intermediate frame when there is enough headroom, then fall back to the required frames under load. It is not a fixed or sustained 60 FPS mode. Render scale, distance and filters can be adjusted in Display settings.

05

Can we race together?

+

Multiplayer is planned, but is not currently available. Follow the GitHub project or our Discord community for development updates. The original game’s multiplayer modes should not be taken as a feature promise for the current 3DS port.

06

How do I update and keep my saves?

+

Open Options → Game → Update to check Stable or Experimental builds. Review the changelog and confirm installation; the game then closes. The updater preserves your ROM, O2R, saves and settings. Time Trial ghosts use the original two save slots in sd:/3ds/MK64/controller-pak.bin. Keep a backup of your MK64 folder.
