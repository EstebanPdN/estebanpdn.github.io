Installation, hardware and the questions that come up along the way.

Still need a hand? ↓
01

Will it work on my Old 3DS?

+

This release targets the New Nintendo 3DS family: New 3DS, New 3DS XL and New 2DS XL. Old 3DS, Old 3DS XL and the original 2DS are not supported.

02

Do I need a Zelda ROM or a DOOM WAD?

+

No NES ROM or commercial DOOM IWAD is required. The release uses Freedoom2 as the base. The CIA embeds its matching game data. For Homebrew Launcher, copy the complete release ZIP's 3ds folder to the root of your SD card. The standalone 3DSX is not enough.

03

Can I use this to run other GZDoom mods?

+

This is a dedicated Legend of Doom port, not a general-purpose GZDoom launcher for the 3DS. Support for other mods is not part of this release.

04

What can I do on the lower screen?

+

Keep an eye on the map, hearts and inventory while the adventure stays above. Tap items to select them and tap the map to change its zoom. Touch controls also work in the menus. Camera input can use the C-stick, touch or both.

05

Why is there no sound on my console?

+

Check that your console's DSP firmware has been dumped to sdmc:/3ds/dspfirm.cdc. In Luma3DS, open Rosalina → Miscellaneous options → Dump DSP firmware. Also check the game's master, music and effects volume settings.

06

What should I send with a bug report?

+

Capture the issue while it is visible, then send the complete new report folder from sdmc:/3ds/legend-of-doom/dumps/.

  • L + R + A · Quick dump - Both screens, raw framebuffers, game state, configuration and diagnostic logs. Includes a memory-map summary, without the large RAM image. Start here for an ordinary bug report.
  • L + R + X · Full dump - Everything in a quick dump, plus the game's readable memory in memory.bin and its map. The memory payload is roughly 136 MiB; allow extra SD space and wait for capture to finish.
  • L + R + Y · Clean dumps - Deletes all saved dump reports to free SD space. Copy or send the reports you need first. Saves, configuration and ordinary logs stay intact.

Include your console model, release version and steps to reproduce. For updater errors, also attach sdmc:/3ds/legend-of-doom/update.log. Use GitHub issues or Discord below.

C:\Forge\LegendsOfDoom\Diagnostics> ▌

Don't explore alone.

Start with a quick dump. Press L + R + A while the problem is visible. It captures both screens, raw framebuffers, game state, configuration and diagnostic logs, without a large memory image.

Need a deeper report? Use L + R + X for a full dump. It adds the game's readable RAM as memory.bin, with offsets in memory-map.txt. The memory payload is around 136 MiB, so leave enough free space on your SD card and wait for the capture to finish.

Free up space afterward. Once you have copied or shared your reports, L + R + Y clears the dumps folder. It leaves your saves, configuration and ordinary logs untouched.

Send the complete report folder with your console model, release version and the steps that caused the issue. For updater problems, also attach sdmc:/3ds/legend-of-doom/update.log.
