PROJECT QUESTIONS
01Is Dusklight available to download?+

Not yet. Dusklight is in early development and remains unreleased. There is no public installation guide or finished build to download.

02Which Nintendo 3DS is the project intended for?+

The current target is New Nintendo 3DS. Old Nintendo 3DS support has not been announced for Dusklight.

03Are the images here running on a 3DS?+

This journal uses original Twilight Princess promotional artwork and hardware photographs. Development captures will appear here when there is more port gameplay to share.

04When will the project be ready?+

There is no announced release date. The current development figure is 10%, as shared by Esteban. Follow the Forge progress page or join our community for project news.
