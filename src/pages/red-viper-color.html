01 / COLOR MODE

Beyond the red.

Familiar pixels. A fresh way to see them.

COLOR / 01

Hand-painted packs.

VBoyColor’s hand-painted packs bring chosen colors to familiar tiles, characters and worlds. A matching pack gives each adventure its own palette.

COLOR / 02

Automatic color.

The combined color mode fills the parts a pack leaves unpainted. When a compatible pack is missing, Auto gives the scene its own color interpretation.

COLOR / 03

Stereoscopic depth.

A separate color image is composed for each eye, preserving the original scene’s stereo geometry. Color can be switched off to return to Red Viper’s original rendering.

The colors are an interpretation of the original graphics, shaped by color packs and Auto.

05 / QUESTIONS & ANSWERS

Before you look inside.

How does the color mode work?

A compatible pack supplies its painted colors. Auto fills the remaining parts, or colors the scene when a compatible pack is missing. The setting can be saved per game or globally.

Do all games use the same palette?

No. Packs are matched to the game’s identity, while Auto interprets its scene. A missing or incompatible pack falls back to Auto; each game and scene still needs its own visual review.

Can I download Red Viper Color yet?

It remains an experimental project in development. Follow the Forge updates for a future release and hardware-testing news.
